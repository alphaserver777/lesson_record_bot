# Уведомления LMS

API `POST /api/internal/lms/notifications` принимает события только от LMS.
Источник проверяется по адресу, а тело подписывается HMAC-SHA256. Повтор с тем
же `event_id` не отправляет второе сообщение в Telegram.

Поддерживаемые события:

- `assignment.submitted` — новая работа ученика;
- `assignment.resubmitted` — повторная сдача;
- `assignment.review_digest` — утренняя сводка работ;
- `lms.health_failed` и `lms.health_recovered` — недоступность и восстановление
  LMS;
- `lab.reserved` — ученик занял общий учебный стенд;
- `lab.ready` — стенд восстановлен и готов к работе;
- `lab.released` — стенд снова свободен.

События стенда содержат имя ученика, идентификатор стенда, время окончания
сеанса и ссылку на запись сеанса в LMS. Они отправляются только
администраторам бота. Ученикам имя другого ученика не раскрывается.
