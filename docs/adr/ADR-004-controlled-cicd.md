# ADR-004: Контролируемый конвейер выпуска и развёртывания

## Status

Accepted

## Контекст

CRM обрабатывает запись и платежи. Запуск рабочего кода из текущей папки или
произвольной фиксации делает невозможным точное восстановление и увеличивает
риск недоступности сервиса.

## Решение

- `develop` и `main` проходят одинаковый набор обязательных проверок;
- выпуск создаётся вручную в GitHub Actions только из текущего `main` и только
  аннотированной меткой `professorit-vX.Y.Z`;
- рабочее развёртывание запускается вручную по метке через защищённое окружение
  `production`;
- сценарий проверяет, что метка аннотирована, указывает на переданную фиксацию
  и достижима из `main`;
- Ansible всегда создаёт и проверяет резервную копию PostgreSQL до переключения
  версии, а при ошибке возвращает предыдущий каталог кода;
- данные PostgreSQL не откатываются автоматически.

## Последствия

Поставки требуют подтверждения владельцем, но становятся воспроизводимыми и
проверяемыми. Для развёртывания нужны защищённые секреты GitHub с ключом SSH и
проверенным отпечатком VM 201. Защита веток и правила окружений задаются в
настройках GitHub, а не хранятся в исходниках.
