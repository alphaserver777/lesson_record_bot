# План Разработки

## M1. Воспроизводимое локальное окружение

- Добавить Nix dev shell для `lesson_record_bot`
- Задокументировать локальный bootstrap на NixOS
- Зафиксировать версии Python и Node для разработки

## M2. Рабочая модель проекта

- Добавить конституцию проекта
- Добавить архитектурные заметки
- Начать журнал ADR для долгоживущих технических решений
- Определить команды verification для типовых изменений

## M3. Стабилизация доменной логики

- Определить единый source of truth для правил записи и расписания
- Снизить дублирование между bot handlers и API Mini App
- Задокументировать границы миграции legacy admin bot flows
- Связать финансовое решение с постоянным `record_dates.id`, а не с изменяемым
  временем занятия

## M4. Качество и безопасность

- Добавлены проверки исходников, Ansible, критических потоков записи и оплаты,
  сборки кабинета, зависимостей и секретов в GitHub Actions.
- Добавлены контролируемые сценарии создания метки выпуска и рабочего
  развёртывания с подтверждением окружений.
- Откат кода выполняется через предыдущий неизменяемый выпуск без
  автоматического отката PostgreSQL.
