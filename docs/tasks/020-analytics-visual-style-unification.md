## Контекст

После перевода дневной аналитики на парные гистограммы в верхней части блока осталась отдельная система цветных статусов:

- `Прогресс`
- `Стагнация`
- `Смешано`
- `Регресс`

Она визуально конфликтует с основной легендой самих гистограмм и создаёт две параллельные цветовые логики в одном виджете.

## Цель

Привести дневную аналитику к единому визуальному стилю:

- одна понятная цветовая система
- summary не должен спорить с цветами графика
- основной акцент должен оставаться на парных столбцах и legend

## Scope

В scope:

- корректировка верхней summary-зоны блока гистограмм
- выравнивание цветов и акцентов с legend/гистограммами

Вне scope:

- изменение analytics API
- редизайн всей аналитики

## Acceptance Criteria

- В блоке дневной аналитики больше нет конфликтующих цветовых статусов.
- Summary и legend читаются как части одного визуального языка.
- Основная динамика воспринимается через гистограммы, а не через лишние разноцветные плашки.
