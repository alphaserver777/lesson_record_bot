## Контекст

Кабинет считает уроки, оплаты и LTV, но не хранит происхождение нового
обращения, этап продажи и причину отказа. Поэтому невозможно посчитать CPL,
конверсию Avito/YouTube в диагностику и оплату.

## Цель

Сделать в прикладной PostgreSQL единую воронку лидов, связанную с профилем
ученика, и дать администратору возможность видеть и менять её в кабинете.

## Scope

В scope:

- таблица `leads` с Telegram-профилем как необязательной связью;
- UTM/source, направление, задача, этап, диагностика, предложение, отказ и
  следующий контакт;
- API для создания/редактирования/списка лидов и сводных метрик воронки;
- экран администрирования для списка и редактирования лидов;
- безопасное сохранение source-параметра Telegram deep link при `/start`.

Вне scope:

- автоматическая синхронизация с Twenty CRM;
- платёжный эквайринг;
- публичная форма без Telegram-авторизации.

## Ограничения

- `student_profiles` остаётся source of truth для данных ученика и расписания.
- Лид не должен создавать дубликат ученика; связь создаётся только после
  подтверждённого Telegram ID.
- Существующие профили и SQLite-бот не должны ломаться до cutover.

## Acceptance Criteria

- каждый новый lead имеет дату, этап и источник;
- UTM и Telegram `start` payload сохраняются без исполнения как кода;
- администратор видит по источникам количество лидов, диагностик, продаж и
  сумму предложений;
- этапы и причины отказа редактируются без изменения исторических оплат;
- API и Mini App успешно собираются, PostgreSQL schema создаётся idempotently.

## Verification

- создать лид через API, получить его в списке и изменить этап;
- проверить агрегат воронки для источника;
- открыть админский экран на desktop и mobile;
- выполнить FastAPI health check и production Vite build.

## Rollback / Safety

- новая таблица аддитивна; rollback состоит в откате приложения, данные лидов
  остаются без влияния на записи и оплаты;
- production bot не переключается в рамках этой задачи.

## Заметки

Twenty будет подключён отдельной задачей только через API, не прямым доступом
к прикладной PostgreSQL.
