## Контекст

Текущий экран аналитики в admin Mini App показывает базовые KPI и простой график по дням, но не отвечает на два практических вопроса:

- кто из учеников приносит основную выручку
- где по дням есть прогресс, регресс или стагнация относительно прошлого периода

Из-за этого аналитика остаётся информативной, но не даёт быстрого визуального ответа на управленческие вопросы.

## Цель

Сделать admin analytics заметно более наглядной:

- показать долю выручки по ученикам через круговую диаграмму
- показать сравнение дохода и количества занятий по дням относительно предыдущего периода
- дать явные сигналы прогресса, регресса и стагнации

## Scope

В scope:

- расширение analytics API данными по profit share учеников
- расширение timeseries API данными сравнения с прошлым периодом
- переработка visual блока аналитики во frontend Mini App

Вне scope:

- внешние chart-библиотеки
- экспорт аналитики в файл
- новая финансовая модель или изменение правил расчёта payments

## Ограничения

- опираться только на существующий source of truth по `payments`
- сохранить совместимость текущих analytics route для frontend
- не затрагивать user Mini App

## Acceptance Criteria

- В аналитике есть круговая диаграмма с долями выручки по ученикам.
- Видно, кто из учеников приносит большую часть cash.
- Блок “Доход и занятия по дням” показывает сравнение с прошлым периодом по каждому дню.
- Для дней различимы прогресс, регресс и стагнация.

## Verification

- Открыть admin Mini App и перейти в `Аналитика`.
- Проверить наличие круга с долями выручки и списка учеников с процентами.
- Проверить недельный режим и убедиться, что текущие дни сравниваются с соответствующими днями прошлой недели.
- Проверить месячный режим и убедиться, что дни месяца сравниваются с соответствующими датами прошлого месяца.

## Rollback / Safety

- Rollback ограничивается analytics API и frontend analytics UI.
- При отсутствии данных аналитика должна показывать корректные empty-state, а не ломать экран.

## Заметки

- Реализация выполнена без внешних chart libraries, через CSS/HTML визуализации.
