# Task: postgresql-runtime-and-historical-lessons-repair

## Status

Done

## Контекст

После переезда рабочим источником данных является PostgreSQL. В runtime-коде
сохранились SQLite fallback и стартовая миграция, которая при каждом запуске
восстанавливала прошлые занятия из оплат. Если время такой оплаты совпадало с
новой регуляркой, старое занятие могло попасть в интерфейс как регулярное.

## Цель

Оставить PostgreSQL единственной поддерживаемой runtime-БД, прекратить
автоматическое создание прошлых занятий и дать безопасную процедуру очистки
ошибочно созданных строк.

## Scope

- обязательный PostgreSQL URL для приложения;
- удаление SQLite runtime-веток и зависимостей;
- startup проверяет только схему и связи, без data backfill;
- отдельный скрипт отчёта и очистки строк, восстановленных ошибочной миграцией;
- PostgreSQL smoke-проверки и инструкция deploy.

## Safety

Очистка выполняется только после PostgreSQL dump и только явным запуском
скрипта с `--apply`. По умолчанию скрипт ничего не меняет.

## Verification

- runtime-код не содержит SQLite URL, `PRAGMA` или `aiosqlite`;
- `compileall` успешно проверяет Python-исходники;
- интеграционные тесты требуют отдельный `TEST_DATABASE_URL` PostgreSQL.
