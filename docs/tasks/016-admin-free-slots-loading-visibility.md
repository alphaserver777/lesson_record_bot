## Контекст

В административном Mini App после предыдущего исправления stale month switch у пользователя всё ещё наблюдается проблема:

- в режиме `Свободные слоты` не виден явный progress bar во время загрузки слотов дня
- из-за этого UI выглядит так, будто ничего не происходит или данные уже окончательны

Текущий admin-экран использует общий detail loading-state для нескольких разных режимов (`Записанные`, `Свободные слоты`, `Бронь`), что делает индикацию загрузки хрупкой.

## Цель

Сделать загрузку свободных слотов в admin-режиме явно видимой и устойчивой:

- в `Свободные слоты` должен гарантированно показываться progress bar
- загрузка слотов не должна зависеть от shared loading-state других detail-flow

## Scope

В scope:

- диагностика admin loading-state для режима `Свободные слоты`
- выделение независимого loading-state для admin free slots
- корректный reset/cancel state при смене месяца и дня
- явный progress indicator для загрузки свободных слотов

Вне scope:

- редизайн admin-календаря
- оптимизация backend month endpoint
- изменение user-flow Mini App

## Ограничения

- менять только admin frontend flow
- не ломать текущую логику загрузки `Записанные` и `Бронь`
- защита от устаревших ответов должна сохраниться

## Текущее состояние

Сейчас progress bar для admin free slots либо не появляется, либо появляется нестабильно.
Вероятная причина: shared `scheduleDetailLoading` и shared request ref используются сразу несколькими async-flow.

## Предлагаемое изменение

1. Выделить отдельный loading-state и request guard для `Свободные слоты`.
2. Показ progress bar привязать именно к загрузке free slots, а не к общему detail loading-state.
3. При смене месяца и сбросе выбранного дня корректно очищать этот state.

## Затронутые области

- `miniapp/src/features/admin/AdminView.jsx`
- возможно `miniapp/src/styles.css`

## Acceptance Criteria

- При открытии admin-режима `Свободные слоты` и загрузке данных виден явный progress bar.
- При выборе другого дня в режиме `Свободные слоты` progress bar отображается до завершения актуального запроса.
- Загрузка `Свободные слоты` не гасится состоянием загрузки `Записанные` или `Бронь`.

## Verification

- Открыть Mini App как админ.
- Перейти в `Свободные слоты`.
- Выбрать день и убедиться, что во время загрузки появляется progress bar.
- Повторить для нескольких дней подряд и при переключении месяца.

## Rollback / Safety

- Rollback ограничивается admin frontend.
- После изменения нельзя потерять защиту от race condition при быстром переключении дней.

## Заметки

- Если проблема частично связана с очень быстрым ответом API, допустимо обеспечить минимально заметное время показа индикатора.
- Реализация выполнена во frontend Mini App:
  - общий detail loading-state разделён на независимые loading-state для `Записанные`, `Свободные слоты` и `Бронь`
  - для `Свободные слоты` добавлен отдельный request guard
  - progress bar для free slots теперь привязан к собственному loading-state и не гасится соседними flow
  - добавлено минимально заметное время показа индикатора для быстрых ответов API
