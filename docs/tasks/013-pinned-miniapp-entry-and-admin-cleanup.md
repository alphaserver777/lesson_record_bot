## Контекст

Сейчас вход в Mini App из Telegram-бота неудобен:

- сообщение с кнопкой входа может потеряться в истории чата
- в сообщении есть лишняя кнопка `Открыть в браузере`, хотя Mini App должен открываться только внутри Telegram
- у администратора всё ещё присутствует legacy-кнопка `Админ меню`, которая больше неактуальна после переноса управления в Mini App

## Цель

Сделать стабильную и понятную точку входа в Mini App для пользователей и администратора, а также убрать устаревший admin UX из бота.

## Scope

В scope:

- закреплённое или стабильно переиспользуемое сообщение с кнопкой `Открыть Mini App`
- единый вход в Mini App для пользователя и администратора
- убрать кнопку `Открыть в браузере`
- убрать у администратора неактуальную кнопку `Админ меню`
- обновить bot UX без поломки notification-only flow

Вне scope:

- полный рефакторинг всего Telegram-бота
- редизайн всех reply keyboards
- изменение Mini App URL или auth flow

## Ограничения

- Вход в Mini App должен открываться только как Telegram WebApp, без браузерной ссылки.
- Нельзя плодить много одинаковых entry-сообщений в одном чате.
- Нельзя ломать notification-only режим бота.

## Предлагаемое изменение

### 1. Закреплённый вход в Mini App

Для пользователя и администратора бот должен отправлять или обновлять специальное entry-сообщение с кнопкой:

- `Открыть Mini App`

Сообщение должно быть легко доступно из любой точки диалога и по возможности закрепляться.

### 2. Только Telegram Mini App

Убрать из entry-сообщения кнопку:

- `Открыть в браузере`

Оставить только `web_app`-кнопку Telegram.

### 3. Чистка admin UX

Убрать у администратора legacy-кнопку:

- `Админ меню`

если её функциональность уже закрыта через Mini App.

## Затронутые области

- Telegram bot handlers
- keyboard builders / reply markup
- возможно тексты и helper-функции отправки стартового сообщения
- `docs/architecture.md`

## Acceptance Criteria

- Пользователь и администратор всегда имеют доступ к кнопке `Открыть Mini App` в чате с ботом.
- Entry-message не требует браузера и не содержит `Открыть в браузере`.
- У администратора больше нет неактуальной кнопки `Админ меню`.
- Новый flow не создаёт лишний спам одинаковых сообщений в чате.

## Verification

- Проверить обычного пользователя.
- Проверить администратора.
- Проверить повторный вызов entry-flow: старое сообщение не дублируется бесконтрольно.
- Проверить, что Mini App открывается только внутри Telegram.

## Rollback / Safety

- Изменение должно быть изолировано в bot UX.
- Если закрепление/обновление сообщения окажется нестабильным, временно оставить обычное одноразовое сообщение, но без браузерной кнопки.

## Результат

- Entry keyboard для Mini App содержит только Telegram `web_app` кнопку `Открыть Mini App`.
- Бот сохраняет `chat_id/message_id` entry-сообщения в профиле и при повторном `/start` переиспользует это сообщение вместо бесконтрольного спама новыми.
- При первом создании entry-сообщения бот пытается закрепить его в чате.
- При `/start` дополнительно снимается legacy reply keyboard, чтобы у администратора не оставалась устаревшая кнопка `Админ меню`.
