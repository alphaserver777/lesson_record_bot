## Контекст

После унификации визуального стиля в дневной аналитике всё ещё оставался лишний слой интерпретации:

- summary сверху дублировал смысл блока
- цвета гистограмм описывали тип метрики, а не состояние дня

Из-за этого взгляд сначала считывал подписи и legend, а уже потом саму динамику.

## Цель

Сделать так, чтобы сам цвет текущих столбцов сразу передавал смысл:

- зелёный — прогресс
- красный — регресс
- нейтральный — стагнация
- смешанный — mixed case

## Scope

В scope:

- убрать верхний summary-блок из дневной аналитики
- оставить компактную semantic legend
- покрасить текущие столбцы по сигналу дня

Вне scope:

- изменение analytics API
- изменение остальных блоков аналитики

## Acceptance Criteria

- Верхний summary-блок над дневными гистограммами отсутствует.
- Цвет текущих столбцов передаёт смысл дня.
- Легенда объясняет цвета состояний, а не дублирует текстовый summary.
