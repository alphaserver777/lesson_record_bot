# CRM и бот Professor IT

Единый рабочий проект CRM, кабинета ученика, HTTP API и Telegram-бота.
Рабочие данные находятся только в PostgreSQL на VM 201; SQLite и прежний
контур Germany2 являются архивом.

## Перед изменениями

1. Прочитайте [AGENTS.md](AGENTS.md).
2. Изучите [архитектуру](docs/architecture.md) и
   [порядок выпуска](docs/DEPLOYMENT.md).
3. Создайте `feature/*` от `develop`; срочное исправление — `hotfix/*` от
   `main`.
4. Не публикуйте текущую рабочую папку: развёртывание выполняется из конкретной
   проверенной фиксации.

Утверждённая базовая версия проекта отмечена меткой
`professorit-v1.0.0`.
